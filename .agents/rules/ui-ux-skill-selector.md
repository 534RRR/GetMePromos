# UI/UX Skill Selection Rule

## Directive
At the start of every project or when the user gives an initial command for a new project/feature involving UI/UX design, you MUST ask the user which UI/UX skill to use:

1. **`design-taste-frontend`** (Taste skill by leonxlnx: Opinionated anti-slop rules, Brief Inference, 3 Dials calibration, viewport-fitted hero mechanics, strict typography & color calibration).
2. **`impeccable`** (Impeccable by pbakaus: 23 design commands like craft, init, audit, critique, polish, bolder, quieter, animate, colorize, typeset, layout, delight, overdrive, live browser iteration).

Always prompt the user to choose between these two skills before proceeding with UI/UX development unless they have already explicitly specified the skill to use.
