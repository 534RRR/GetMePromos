# Workspace Directives & Design Skills

## UI/UX Skill Selection Protocol
At the start of every project or when the user initiates a new project / major UI/UX redesign, always prompt the user to choose their preferred design skill:

- **Option 1: `design-taste-frontend` (Taste Skill)**
  - Opinionated anti-slop rules, Brief Inference, 3 Dials calibration (`DESIGN_VARIANCE`, `MOTION_INTENSITY`, `VISUAL_DENSITY`), viewport-fitted hero mechanics, strict typography and color palettes.
- **Option 2: `impeccable` (Impeccable by Paul Bakaus)**
  - Comprehensive design system with 23 specialized commands (`craft`, `init`, `audit`, `critique`, `polish`, `bolder`, `quieter`, `animate`, `colorize`, `typeset`, `layout`, `delight`, `overdrive`, `harden`, `live`), 35 reference playbooks, and deterministic anti-pattern checks.

Prompt the user before proceeding with any UI/UX implementation unless they have already explicitly designated which skill to use.
